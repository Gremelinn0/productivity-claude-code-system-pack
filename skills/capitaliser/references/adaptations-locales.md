# Adaptations locales

Cette copie est portable. Aucun compte, dépôt privé, registre personnel ou outil métier
n'est requis. Charger les instructions déjà autorisées du projet ou de l'espace de travail.
Si elles désignent un profil de capitalisation, le lire ; ne pas rechercher hors périmètre.

Dans un projet qui utilise un fichier `.claude/capitaliser.local.md`, le profil peut préciser
les sources canoniques, registres de livrables, contrôles et consommateurs propres au projet.
Il adapte les adresses et les outils ; il n'ajoute pas un second processus de capitalisation.

Sans profil, appliquer le cœur de la compétence avec les sources existantes. Sans outil
persistant, utiliser NON PERSISTÉ. Ne pas inventer de registre ni de test pour rendre un vert.
